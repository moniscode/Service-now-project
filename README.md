## Overview

This project demonstrates how to customize form behavior in ServiceNow's Incident module using two client-side features:

- **Client Scripts**: JavaScript that runs in the user's browser to react to form events such as load, change, and submit.
- **UI Policies**: Rule-based, low-code configuration that makes fields mandatory, read-only, or visible/hidden depending on conditions.

The repository includes the step-by-step implementation guide, the test report, brainstorming notes, and the final project report.

## Concepts Covered

- Creating and configuring **Client Scripts** on the Incident form
- Creating and configuring **UI Policies** (and UI Policy Actions)
- Controlling field behavior: mandatory, read-only, and visibility
- Testing client-side behavior and documenting the results
